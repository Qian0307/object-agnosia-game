# 物體失認症體驗遊戲（Object Agnosia Demo）

心理學課堂報告「看見，不等於認出：物體失認症」的互動教材。

線上版：https://qian0307.github.io/object-agnosia-game/

## 關卡

| 關卡 | 模擬的歷程 | 直接連結 |
|---|---|---|
| ① 碎裂的輪廓 | 統覺型：形狀建構失敗 | `#frag` |
| ② 小窗偷看 | 整合型：只能處理局部 | `#peek` |
| ③ 剪影 vs 線條畫 | 整合型研究的材料 | `#sil` |
| ④ 換個角度 | 物體恆常性 | `#view` |
| ⑤ 重疊圖形 | 改編自 Poppelreuter 重疊圖形作業 | `#over` |
| ⑥ 腦區地圖 | 腹側／背側路徑與病灶 | `#brain` |

## 說明

- 教學模擬，不等於病人的真實知覺經驗，也不是標準化測驗。
- 物品圖片為 AI 生成的教學素材；剪影由照片自動轉換；腦區圖為示意圖。
